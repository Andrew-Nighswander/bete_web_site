# Snippets

Code from the **Snippets** plugin (in the WordPress admin bar).

**To export:** go to **Snippets → All Snippets**, tick the snippets, and choose **Export** from Bulk actions. Upload the exported file here. You can also copy a single snippet's code into a file named after the snippet, e.g. `redirect-old-product-urls.php`.

Add a line at the top of each file saying what it does and whether it's active.

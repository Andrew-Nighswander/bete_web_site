# Cornerstone exports

Backups of layouts, headers, footers and reusable components.

**To export:** in Cornerstone, open the **Layouts**, **Headers**, **Footers** or **Components** list, open the item's menu (⋯), and choose **Export**. Upload the file here.

Name files with the type and ID, e.g. `layout-3499-spray-lances.json` or `header-78-main.json`, so they're easy to match to the site. See [docs/how-the-site-is-built.md](../../docs/how-the-site-is-built.md) for what the IDs mean.

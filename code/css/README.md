# CSS

**Where to copy it from:**
- Global CSS: **Cornerstone → Theme Options → CSS** (or **Pro → Theme Options**)
- Page or layout CSS: open the page or layout in Cornerstone, then **Settings → Custom CSS**

Save each as its own `.css` file. Add a comment at the top saying where it lives on the site, e.g. `/* Theme Options > CSS */` or `/* Layout 3499 (Spray Lances) > Custom CSS */`.
